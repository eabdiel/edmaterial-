Start with the [Think Python course](thinkpython/README.md) and its [browser-based lessons](thinkpython/index.html). The collection covers Python foundations, reports, Flask interfaces, SAP APIs, and OCR topics.

Open individual HTML lessons in a browser; use the setup instructions in each lesson for executable examples.
